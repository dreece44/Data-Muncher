# Data-Muncher

DataMuncher finds wasted space on phones (empty and unreadable files,
duplicate and blank photos, unused apps) and helps users clear it.

| Package | What it is |
|---|---|
| [`packages/scan_engine`](packages/scan_engine) | The scanning engine (pure Dart). Runs on phones and on a computer, with a command-line scanner for testing. |
| [`packages/scan_engine_flutter`](packages/scan_engine_flutter) | Android and iOS adapters: storage, photos, apps and permissions on real devices. |

Built with Flutter/Dart. See each package's README for how to test it.
